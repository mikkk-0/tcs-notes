# Конспекты по TCS

Статический сайт для чтения PDF на телефоне. В нём два курса, страницы тем и ссылки на конспекты, задачи, подсказки (где они есть), решения и экзамены. Игра и внешние зависимости сайту не нужны.

## Обновить материалы

Курсы читаются из `~/lessons/self_cources/fpt_course` и `~/lessons/self_cources/distributed_algorithms_course`. Запустите из этой папки:

```bash
python3 build.py
```

Скрипт копирует готовые PDF, а недостающие создаёт из Markdown с помощью `pandoc` и `pdflatex`. Исходные курсы он не меняет. Затем обновите репозиторий сайта: закоммитьте и отправьте изменённые `catalogue.json`, `catalogue.js` и `pdf/`. На GitHub Pages выберите публикацию из корня ветки `main`. После отправки изменений сайт обновится автоматически.

Для локального просмотра можно открыть `index.html` в браузере. При необходимости запустите локальный сервер:

```bash
python3 -m http.server 8000
```

Адрес локального сервера: <http://localhost:8000/>.

## Публикация

GitHub Pages обслуживает статические файлы бесплатно для публичного репозитория. Отдельный сервер или постоянно включённый компьютер не нужны. Если репозиторий называется `tcs-notes`, адрес будет `https://ИМЯ-ПОЛЬЗОВАТЕЛЯ.github.io/tcs-notes/`. В разделе **Settings → Pages**: **Build and deployment → Deploy from a branch**, ветка `main`, папка `/ (root)`.

Все PDF и решения в таком репозитории доступны всем по ссылке. Не добавляйте в него личные черновики и свои ответы на экзамен.
