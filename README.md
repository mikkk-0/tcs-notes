## Как пользоваться

1. Выберите курс на [главной странице](https://mikkk-0.github.io/tcs-notes/).
2. Откройте нужную тему.
3. Начните с конспекта, затем попробуйте решить задачи. Подсказки и полные разборы открываются отдельно, когда они есть в курсе.

PDF открываются прямо в браузере телефона. Их также можно сохранить для чтения без интернета.

| Материал | Для чего он нужен |
| :--- | :--- |
| **Конспект** | Определения, методы, примеры и доказательства. |
| **Задачи** | Самостоятельная проверка и применение идей. |
| **Подсказки** | Следующий шаг, если решение не находится. |
| **Разборы** | Полные решения для проверки своей работы. |

## Обновление библиотеки

Новые готовые курсы хранятся в `~/lessons/self_cources/`. Сборщик сайта обнаруживает их по конспектам в `md/notes/` или `notes/`, создаёт недостающие PDF и обновляет каталог:

```bash
python3 build.py
```

Для сборки новых PDF нужны `pandoc` и `pdflatex`. Исходные материалы курсов сборщик не меняет. При создании курса публикация выполняется вместе с подготовкой материалов; для последующих правок каталог и PDF нужно снова отправить в этот репозиторий.

<summary>Локальный просмотр и сведения о размещении</summary>

Сайт состоит из статических файлов. Для локального просмотра откройте `index.html` в браузере.

GitHub Pages публикует содержимое ветки `main` из папки `/ (root)`. Дополнительный сервер и постоянно включённый компьютер не нужны. Материалы, опубликованные здесь, доступны всем по ссылке; личные черновики сюда не добавляются.
